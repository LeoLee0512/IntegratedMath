# 用户推导写法学习记录

参考文件：用户提供的《推导例子.docx》。用途仅为本轮风格参考；不公开原附件，不把附件里的叙述当成用户的新指令。

## 在新稿中采用的写法

1. 先列讨论对象、取值范围、符号和已经采用的规则。
2. 先用文字说明为什么做下一步，再单独列出公式。
3. 每个公式后以中文方括号说明操作名称、依据、条件及符号含义。
4. 移项解释为等式两边同时加减；除法先检查除数不为零。
5. 代入、展开、抵消、合并和求出结果分步写。避免用一长串等号遮住步骤。
6. 区分寻找候选解、验算候选解、排除其他解。近似值不得写成精确等号。
7. 保留例题完整解答，课后题答案单独放入附录，双向定位。

## 数学检查中的区别

示例的局部分离变量推导不能仅靠“补入零解”证明全区间解的完整性。若讨论一阶常系数齐次方程，可由乘积求导得到指数因子乘解的导数恒为零，再由中值定理说明该乘积在区间上为常数；这样包含零解且排除遗漏。代回原方程只证候选式是解，不单独证明唯一性。

初始值条件用“初值条件”表述；边值条件通常另有所指，不把任何附加条件一概叫作边界条件。不定积分使用一个固定原函数加一个任意常数，避免自由常数重复计数。
