## 一般证明与定义域

| 项目 | 实际核查 |
|---|---|
| 比定义 | a:b=a/b仅b非零；a可零，后项可负，纯数许可不自动成为实物数量许可；顺序不可随意交换。 |
| RP1正向 | 两商同q给bq=a、dq=c，再结合交换得ad=bc。字母是有理数而非只整数代表分量，证明层次正确。 |
| RP1反向 | b非零先令q=a/b；交叉等式推b(dq)=bc，消b得dq=c；d非零才以方程唯一性认q=c/d。前项可零，不误消前项。 |
| 非零条件反例 | b=d0时交叉两侧0，但1:0及2:0未定义，不把未定义式说成相等或不等。两个零前项配非零后项则合法。 |
| RP2尺度 | k、b非零保证kb非零，交叉等式保商。比例等价于唯一非零k使c=ka,d=kb；k=d/b非零来自d非零，分子零也可由后项确定。 |
| 正数量限制 | 纯数允许负k；若b,d均正则d/b正，须额外根据模型保正，不混同代数非零和物理正倍率。 |
| RP3定义域/存在 | T正、m非负、n正给w=m+n正及λ=T/w正。x=λm非负、y=λn正，总和T，比例由λ非零保持；Tm/w形式另由乘法方程唯一性解释。 |
| RP3唯一 | 对其他x′,y′先反写m:n=x′:y′，按RP2参数方向得到μ，再和为T使μw=T，唯一得μ=λ。没有只展示候选便结束。 |
| RP3边界 | m0给x0,yT且比分母合法；T0、非负分量只可双零，实际比未定义；负权重并不自动适合非负分配。 |
| RP4部分/整体 | 公共非零λ约去得x/T=m/w、y/T=n/w；反向交叉并用w非零求唯一x/y，恢复RP3全部条件。 |
| 固定倍率记录 | 多条记录要求同一k；u0时检查v=k0而非除以零。两列增加及共同加项不意味着固定比值，有限记录不代表未观察的全部情形。 |
