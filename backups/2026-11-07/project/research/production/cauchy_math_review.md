## 定义与CY1—CY4

| 对象 | 独立核查 |
| --- | --- |
| 柯西定义 | `∀ε>0 ∃N ∀m,n∈N`，同一个N约束所有尾部指标对，m、n均不小于N；不允许把N放在给定m、n之后。m=n虽合法但不替代不同指标对。 |
| 准确否定 | `∃ε₀>0 ∀N ∃m,n≥N`且距离至少ε₀。固定正误差在最外层；坏指标可随N变化；严格小于的否定为大于等于，等号足以反驳。 |
| CY1：收敛⇒柯西 | 给ε后用ε/2选同一个原列阈值，对m、n各使用一次；差的分解、绝对值取反及三角不等式给严格总界ε。没有用已知极限之外的额外存在结论。 |
| CY2：柯西⇒有界 | 误差1对应阈值N，以合法尾项a_N作为固定参照，先控全部n≥N；引用SA1证明中独立于收敛假设的有限前缀构造，得C_N≥0。M=C_N+1+|a_N|覆盖前缀和尾部，N=0时C₀=0、a₀合法，不要求空集最大元。 |
| CY3：柯西且有收敛子列⇒原列收敛 | 原列柯西阈值N与子列输入阈值J分清。取j₀=max(N,J)，用SS1的kⱼ≥j得到k_{j₀}≥N；固定这个子列项后再任取原列n≥N。两项ε/2误差同控全部尾项，j₀不需随n改变。未要求kⱼ=j，也未错误要求原列输入N等于子列输入J。 |
| CY4：实数柯西判据 | 反向严格按CY2⇒全列有界⇒SS3/BW给收敛子列⇒CY3给全列收敛。正向CY1已独立证明；唯一性引用SL2。没有把柯西完备性先作为公理，也未凭一个任意有界子列直接推断全列收敛。 |
| 有限改动 | H=max(N,K)同时保证柯西尾部和逐项相同，交换a、b给反向。只保留柯西性，未宣称全列数值界不变。 |

## 邻差反例的完整性

对于xₙ=√(ν(n)+1)，每个根号内至少为1，RS1与RS3给xₙ≥1。相邻输入的平方差为1，两个根非负，所以平方反映严格序给xₙ₊₁>xₙ。差平方恒等式给

`(xₙ₊₁−xₙ)(xₙ₊₁+xₙ)=1`。

分母至少为2，除法合法，正倒数反序给`0<xₙ₊₁−xₙ≤1/xₙ`。原稿所称“平方根保序”在此由已引用RS1对两非负根的平方比较直接得到，不需要连续性定理。

任给拟议界B≥0，以RA1选ν(N)>B²，非负平方反映序推出x_N>B；故全列无界，由已独立证明的CY2排除柯西性。再任给ε>0，取t=1/ε>0，选ν(N)>t²，对所有n≥N统一得xₙ>t，进而邻差绝对值小于1/t=ε。这里既证明了全称尾部界，也证明了实际无界反例，没有只用相邻差的几次计算或“逐项增大”冒充无界证明。
