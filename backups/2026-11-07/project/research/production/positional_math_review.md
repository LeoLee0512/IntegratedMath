## 定义、一般定理与依赖

| 对象 | 实际检查与结论 |
|---|---|
| 底数与数字 | b≥2；数字为d<b的自然数。有限有序表与集合区分，超过十的底数不强行要求单字符数字；空表仅辅助，零规范为[0]。 |
| 递归求值 | 对每个固定输入表使用自然数对(i,v)作状态，T由固定表和当前位置唯一决定，表尾保持，故为固定且全定义的更新函数。B1.1递归原则适用。共同前缀逐轮相同给出V(A,d)=bV(A)+d。 |
| P1位值展开 | 对表长归纳，有限和的分配另说明按项数归纳；交换、结合与幂递归解释位置升高。适用于任意自然数系数，不误加数字上界。 |
| P2正最高位 | 初项为正，正底数乘正值再加非负数字保持正；可用于所有非空高位前缀。 |
| P3商下降 | n>0且b≥2；商零直接小于n，商正经q<2q≤bq≤n。零输入不套用此引理。 |
| P4存在 | 对数值强归纳；零独立；正数先用已证带余除法，商零得单项，商正且严格较小才能使用归纳假设，再附加末位。 |
| P5唯一 | 零规范先处理；正数分出末位及可能为空的前缀。唯一商余同时确定商与末位；商零用P2排除非空前缀，商正用P3及强归纳确定整个前缀，故连长度也相同。 |
| 外部除法依赖 | D1固定正除数对被除数普通归纳，余数后继严格小于或等于除数的分支穷尽；唯一性用商的三歧性、严格上界与加法消去，未借位值。除法算法在声明的有限基本操作模型下执行输入指定的有限轮数。 |

依赖方向已实际成立：Peano及普通归纳→加法和乘法→自然序→强归纳与下降界；除法由普通归纳和自然序建立；位值存在唯一性才用除法和强归纳。没有以位值唯一性证明除法，再用除法倒证位值的循环。

## 两种算法分别审查

**反复取商。** 正输入每轮商严格小于当前数，由O11排除无限轮。每轮调用的B1.4除法已经给出有限操作过程。零输入直接输出[0]。逐行核对不变式N=Aᵢ+pᵢnᵢ：下一轮分解代入后依次使用分配、乘法结合、加法交换结合；辅助量pᵢ=bⁱ、Aᵢ为已存余数的位权和由普通归纳得到。结束时当前数为零；最后余数等于本轮正输入而非零，因此反序输出最高位非零。存在唯一性与算法正确性没有混为一个未经证明的断言。

**逐次合法进位。** 任意有限自然数系数表、任意超标位置；c≥b保证局部商q>0。位权关系与分配律证明两项局部贡献不变，即使新增高位零也成立。设b=t+1，b≥2保证t>0；全部系数和满足M旧=M新+tq，正积给严格下降。这个量与位数无关，因此允许进位新增高位，且不要求预先指定进位顺序。每一步只处理有限表和一次有限除法；尚有超标项即可继续，O11排除无限次进位。去掉前导零另用表长严格下降并始终保留一项，值保持后由P5识别唯一规范结果。

两种终止证明使用不同的自然数值：取商使用当前数，进位使用系数总和。没有将取商算法的终止直接套给任意进位顺序。正文没有宣称这些朴素算法具有效率界；这里的有限执行是在前文明确的基本操作模型内。
