## 证明依赖与条件

| 对象 | 实际检查与结论 |
|---|---|
| O1前驱分类 | 存在性由普通归纳，零不能是后继由P3，唯一性由P4；未从存在前驱偷推任意重复操作终止。 |
| O2零和 | 非零第二项写成后继，递归加法使总和为后继，与零矛盾；再用加零律确定第一项。没有借大小关系。 |
| O3消去 | 对公共左加数普通归纳，后继注入性逐步消去；右消去来自已证交换律。没有借减法。 |
| 序的定义与O4 | 非严格序用自然数加法见证，严格序用后继增量见证；反对称性通过零和与消去建立，传递性通过见证相加建立。 |
| O5严格序关系 | 严格序等价于非严格序加不等；零的最小性及混合传递不借三歧性。 |
| O6后继比较 | 分别核对S(a)≤b与a<b、a<S(b)与a≤b，以及同时取后继的等价；使用加法递归与后继注入性，不提前使用除法。 |
| O7三歧性 | 归纳性质量化所有第一输入，对第二输入普通归纳；零或后继分类覆盖所有对象，互斥性由已有严格序性质保证。 |
| O8加法保序与反映 | 两种关系、两个方向均给见证或消去依据；不是默认允许相减。 |
| O9乘法保序 | 非严格保序允许零因子，严格保序要求正因子；后继乘法及分配律产生严格见证。正积、零积与正因子反映比较均由已证结果推出。 |
| O10强归纳 | 辅助性质Q(n)为所有m≤n满足P；起点处理空的严格前驱范围，归纳步完整证明Q(S(n))，最后代入m=n。没有借良序或最小反例。 |
| O11下降步数 | 先用普通归纳说明有界索引清单有限；对起点强归纳，零步单列，k=S(l)时尾链l步且起点m<n，得到k≤S(m)≤n。量词包括任意有限链，不先假定运行结束。 |
| 无限链与算法适用 | 任意无限链截取S(n)次下降即矛盾。算法应用明确要求单步有限完成且未结束时可继续；弱下降反例有效。 |

特别核对新增文字：O9的两个正因子之积为正没有删除因子条件；O11由k非零得到0<k，再由O6得到1≤k，因而x₁索引存在；尾链的索引与比较均在原链范围内。普通归纳→自然序→强归纳→下降界的方向成立。练习7的最小元素结论在强归纳之后才证明，并未倒用来证明O10。

## 八题与反例

| 题 | 审查结果 |
|---|---|
| 1 | 四的前驱三及其唯一性分别落实命名与后继注入性，零无前驱由P3。 |
| 2 | 2≤5的见证为3，2<5的见证为2；由反对称性及2≠5排除反向比较。 |
| 3 | a+c=a用消去，a+c=0用零和，两者区分正确。 |
| 4 | a<S(a)成立；a=1、b=2否定S(a)<b的错误加强，正确结论S(a)≤b及同时后继的严格等价均有定位。 |
| 5 | 两类比较均先展开见证再消去共同加数，不依赖自然数减法。 |
| 6 | 零因子毁掉严格保持与比较反映；正因子情形通过三歧性排除反向比较。 |
| 7 | 在经典反证语境下强归纳证明每个n不在A会与非空矛盾，正确得到最小元素；反对称性给唯一。 |
| 8 | 任意已执行前缀步数≤5，六步前缀矛盾；常值5反驳仅非严格下降。单步可完成的条件保留。 |
