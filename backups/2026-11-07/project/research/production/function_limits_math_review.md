## 定义与适用条件

`D⊆ℝ`、`f:D→ℝ`与`c∈ℝ`分别声明，`c`不必在域中。相对去心邻域既要求输入在D内，也要求正距离，明确排除了中心点。积点的定义要求每个正半径内存在实际去心输入，足以排除单点域、空域带来的空真。对正实域取`r/2`、对全实域取`c+r/2`的积点见证均合法。

极限量词顺序为先误差、再半径、最后输入；半径不能依赖随后任取的输入。固定候选的否定含有固定正误差、任意正半径、一个依赖半径的坏输入，以及误差的弱反向不等式。正文明确区分排除一个候选和排除全部实候选。这里否定的是已有积点假设下的误差条件，没有错误声称无积点时能找到任意小去心坏点。

## FL1—FL7逐项核对

| 项目 | 独立核对结果 |
| --- | --- |
| FL1唯一性 | 假定不同极限后`d=|L−M|>0`；两半径取正的较小者，积点保证同一个输入可用于两份误差界，三角不等式给`d<2d/3<d`。没有从空的去心域取得不存在的输入。 |
| FL2基本例 | 常数函数用半径1，实值包含函数`u:D→ℝ, u(x)=x`用半径ε；仅当`D=ℝ`才是该集合的恒等函数。积点条件保留，点值不参与去心误差。 |
| FL3局部相同 | 两函数具有相同域，且固定去心邻域内相等。取极限半径与固定邻域半径的较小者；反向只交换相等关系两端即可，条件未改变。 |
| FL4限制域 | 一般限制只有从D到E的方向，E自身必须以c为积点。特殊E为固定去心邻域时，先证明E保积点，再缩小半径使D内的所有待检输入进入E，方可反推。没有把反向扩大到任意子域。 |
| FL5有限线性运算与绝对值 | 和用两份ε/2与共同半径。常数倍先单列零系数，非零时使用正数绝对值。差由已证和及负倍推出；绝对值由反三角不等式直接控制。所有逐点运算具有共同域。 |
| FL6乘积 | 先用误差1得去心局部界`|f(x)|<A=1+|L|`，不宣称全域有界。加减中间项`f(x)M`后的分解正确；两误差分母均正，三半径取较小者使局部界与两误差同时有效。 |
| FL7倒数及商 | 非零极限给`b=|M|>0`；由反三角不等式证明局部`|g(x)|>b/2`。在D的任意小半径内再缩到此非零邻域，证明实际商域H仍以c为积点；倒数与商只在H求值。 |

FL6严格界的零边界已单独检查。第一项先用非负乘法得到`|f(x)||g(x)−M|≤A|g(x)−M|`，再由`A>0`及误差界取得严格小于ε/2；即使误差为零也没有错误使用严格放大。第二项先把`|M|`放大为正系数`|M|+1`，再使用严格误差界，因此`M=0`时仍成立，不会由乘零推导错误严格不等式。

FL7的倒数误差恒等式在两个分母非零后才使用。分母`|g(x)|b>b²/2>0`允许正倒数反序；乘以可能为零的分子时写成弱不等式，随后乘以正数`2/b²`并代入严格误差界，才取得严格小于ε。分子为零时此链仍正确。商的证明先限制f到H，再将它与H上的倒数应用FL6；不是把两个不同域的函数直接当成共同域乘积。

分母极限为零时正文明确不应用FL7，并用实际约分后为常数的商与正域倒数反例说明结果可能不同。没有定义或使用无穷实数值。

## 全部八题与候选反驳

| 题号 | 完整解答核验 |
| --- | --- |
| 1 | 正域以`r/2`见证积点；单点域以半径1见证非积点。删积点条件后每个候选都通过空真蕴含，解释了唯一性证明失效的确切步骤。 |
| 2 | 恒等函数用δ=ε证明候选0。排除候选1固定ε₀=1/2，任给δ取`min(δ/2,1/4)`，输入非零且在半径内，误差至少3/4。没有用中心点反驳去心条件，也没有误把排除1说成无任何极限。 |
| 3 | 所有去心输入使用仿射分支；δ=ε/2给严格误差界。中心值7或任意其他实数不影响论证，结论没有扩大到任意附近改值。 |
| 4 | 正、负子域均给出积点见证，故原域也保积点。任意假设的原域极限L经FL4及FL1被迫同时等于0和1，排除了全部候选。该证明不依赖未定义的左右极限法则。 |
| 5 | δ=ε/(|a|+1)>0对所有实系数成立。先用弱系数放大，再以正系数取得严格界；`a=0`无需除以零。反三角不等式给同一半径下的绝对值极限。 |
| 6 | 先限定`|x−2|<1`得`|x+2|<5`，再取`min(1,ε/5)`；差平方与绝对值乘法给严格误差界。局部界不被错误延伸为全域界。 |
| 7 | 分母极限为0，所以明确排除直接应用FL7。实际域为`ℝ\{1}`，以`1+r/2`证明积点；仅对非零分母合法约分为x+1，得到极限2，保留原商在1无定义的区别。 |
| 8 | 非零域上x/x恒为1且0为积点。对正域1/x，任给L固定ε₀=1，任给δ取`min(δ/2,1/(|L|+2))`；输入正且小于δ，正倒数反序给`1/x≥|L|+2`，因而误差至少2。L任意，故排除全部有限实候选。 |

题4采用限制域与唯一性的间接排除，题8采用显式量词坏输入的直接排除，两种方法都覆盖所有实候选。题2只需排除题设指定候选1；这一区别在答案中保持清楚。
