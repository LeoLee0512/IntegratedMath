## 全称证明与边界

| 项目 | 独立检查结论 |
|---|---|
| RM1合法性 | ac为整数，b,d正保证bd正，分子允许负或零。 |
| RM2代表无关 | 从ab′=ba′、cd′=dc′经整数重排得(ac)(b′d′)=(ab′)(cd′)=(ba′)(dc′)=(bd)(a′c′)；无有理数规律循环使用，无非零分子条件。 |
| RM3零一及交换结合 | 乘一返回原对；乘零得到(0,b)再用零类判据识别，未误称逐项等于(0,1)。交换/结合由整数对应分量相同推出，中间分母均正。 |
| RM4分配 | 左代表(N,D)，N=a(cf+de)、D=b(df)；右分子展开为bN，右分母为bD。合法性分别检查，N(bD)=D(bN)证等价，不假称两代表相同。右分配在左分配和已证交换后推出。 |
| RM5嵌入 | j(m)j(n)=[(mn,1)]=j(mn)，一般j(m)[(a,b)]=[(ma,b)]直接按定义；单射不被冒作运算兼容证明。 |
| RM6符号 | 先从分配及乘零得rs+r(-s)=0，调用加法相反数唯一；再用交换和双取反证明其余公式。全部包括零，只谈相反数恒等式，不预用Q大小。 |
| RM7零积 | 正分母输出使零判据给ac=0；使用已证整数M7推出a0或c0再返回类零。反向由乘零。没有借后面的倒数。 |
| RM8消去 | rt=st推出(r+(-s))t=0，排除t0，随后两侧加s严格恢复r=s；左因子用已证交换化归。零因子反例取r0,s1，嵌入确保不同。 |

依赖链为整数运算→乘法良定义→乘法与分配律→相反数规则→分子零积→非零消去。外部库可能采取倒数先行的证明顺序，但本稿不借该路径，故与下一单元RD3之间无循环。

正文规范化例(-6,15)到(-2,5)有交叉积−30及贝祖证据−4+5=1；分配示例(9,36)/(18,72)交叉积648，规范(1,4)的两交叉积与互素证据已补并复查。

## 实现与冻结有限验证

实际读取完整`rational_multiplication.py`、完整验证脚本以及最终31例JSON，逐一核对报告所记录六份源码哈希均与磁盘文件一致。没有重新运行测试或刷新报告。冻结验证时间为2026-10-27T16:26:42.379214+00:00，状态passed。

`multiply`验证两输入后按整数(ac,bd)计算并规范化。`reciprocal`先验证正分母记录，分子零即抛出ValueError，分子正时取(b,a)、分子负时取(-b,-a)，再规范化；分支所用符号是整数次序。`divide`先验证被除数记录，再计算除数倒数并调用乘法。布尔、浮点、字符串及非二元记录被既有输入层拒绝，零或负分母不进入代表域。任意零类代表都因分子零被拒绝取逆或作除数；零被除数与非零除数则正确返回(0,1)。实现输出是规范整数代表，不是无限等价类本身。

测试独立参考为标准库Fraction，乘法、倒数、商逐项与精确规范元组比较。测试中的1/f为整数一与Fraction的精确运算，不涉及浮点；生产实现不依赖Fraction。换代表通过两个正整数倍数分别缩放两输入，归一化输出比较不会把不同原始代表误作不同有理数。

固定范围：分子−6至6、分母1至5，共65份记录，其中60份非零、5份零；4225对乘法，3900对合法除法，325对零除数拒绝。两组缩放共8450次换代表；对非零除数同时核验商不变。分子−2至2、分母1至3共15份小记录，分别产生3375组结合律和分配律检查，2700组共同因子非零的乘法消去检查。整数嵌入输入−8至8，共289对，第二整数非零时另检查嵌入除法与旧负分母记号。12类非法输入分别经过倒数及两个二元函数的两个参数位，共60次拒绝；零倒数的5次和零除法的325次另列，未混入非法记录计数。

独立按循环范围复算：65=13×5，60=12×5，4225=65²，3900=65×60，325=65×5，8450=2×4225，3375=15³，2700=15²×12，289=17²，60次非法拒绝=12×5。报告的计数与实际脚本吻合。分配律及零积检查属于有限定理实例核验，不声称另有对应生产API。

最终31个明确实例加入书稿超网格数据，且每例除固定期待值外还与Fraction独立核对。已实际检查(-6,15)*(5,7)与(2,3)*(-15,35)同得(-2,7)，(-2,3)*(10,8)得(-5,6)，(2,4)*(-6,10)得(-3,10)，负分子倒数(-6,15)得(-5,2)，(-5,6)/(-2,9)得(15,4)，乘回得到(-5,6)，(6,5)/(-3,7)得(-14,5)，乘回得到(6,5)，共同因子两路线同得(-21,20)，负整数除数两例得(2,5)/(-2,5)，连续除法两括号得(1,6)/(3,2)。正文保留未简代表；代码返回规范代表，比较时按类判据解释差别。
