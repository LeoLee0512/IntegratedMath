## 全称定理与依赖方向

| 对象 | 独立核查 |
|---|---|
| RO0整数反映 | K>0且KA≤KB，若B<A则KB<KA≤KB矛盾；严格反映先得A≤B再排A=B。只用整数M9、整数三歧与混合传递，不预用Q序。 |
| 定义域 | 合法代表b,d正时r≤s iff ad≤bc，严格同式换<；负分母书写必须先转号。 |
| RO1同时换代表 | 先乘b′d′>0，用ab′=ba′及cd′=dc′重排为bd(a′d′)与bd(b′c′)，再消bd>0；≤/<分别双向，没有隐藏负分子消去。 |
| RO2序律 | 自反、反对称接类判据；传递将ad≤bc乘f正、cf≤de乘b正后连接，消中间d正得af≤be。三歧由两个交叉整数，严格 iff ≤且≠，混合传递排等号完整。 |
| RO3嵌入与符号 | j(m),j(n)分母1使比较双向归整数；与零类交叉比较得非负/正/非正/负四分子判据，零不属于严格正负。 |
| RO4平移 | 输出交叉式分别展开为(ad)F+H及(bc)F+H，其中F=ff>0、H=(bd)(ef)可任意符号。先整数消同加项，再正因子消F，≤/<各自双向，无未定义幂操作。 |
| RO5取反 | 比较-s与-r归为-(bc)≤-(ad)，整数取反双向反序得原比较，严格同理。 |
| RO6乘法 | 正因子t=(e,f)给e>0，从新交叉式消ef>0；负因子先u=-t>0再取反，零因子单列且提供不能反映≤的反例。仅非严格单向允许t≥0。 |
| RO7倒数 | 直接用既有正/负分子倒数代表判同号，逆非零与双逆提供反向；不以符号预证倒数存在。 |
| RO8除法 | t非零后以同号t逆作乘数，正保持、负反转、两种比较均双向；零除法未定义，不能类比乘零变相等。 |

依赖方向为整数反映→比较定义良定→序律/符号→平移与取反→符号敏感乘法→既有倒数的同号→除法比较。没有有理数序或绝对值循环。乘积符号推论逐分支含零，不将非负与严格正混同。

正文负数比较(-2/3,-3/4)、分母增大的正负反例、负分母非法交叉法和三种共同乘数均核对。负除数例正确输出-5/6<5/4，交叉整数−20<30；原严格比较乘零只得到相等，不反推原序。
