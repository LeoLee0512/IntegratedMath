## 全称证明与条件检查

| 项目 | 实际审查内容 |
|---|---|
| RA1合法性 | ad+bc是整数，b,d正保证bd正，分子可负或零。尚未借用Q次序。 |
| RA2代表无关 | 两输入同时变化，以ab′=ba′、cd′=dc′重排四因子乘积，推出(ad+bc)(b′d′)=(a′d′+b′c′)(bd)，再用整数交换写成标准交叉等式。没有取消分子或预用Q交换/结合。 |
| RA3零/交换 | 零代表(0,1)给逐项相同输出；交换由整数两运算交换律推出代表逐项相同。 |
| RA3结合 | 左分子(ad+bc)f+(bd)e与右分子a(df)+b(cf+de)分别只用整数分配/结合展开为(a(df)+b(cf))+b(de)；分母由整数结合相同，所有中间输入正分母。 |
| RA4相反数 | 输出(-a,b)合法，代表无关用整数符号等式；相加得到(0,bb)，再用R4识别零类，未把该对误写成(0,1)。两次取反与零取反直接由整数规则。 |
| RA5嵌入 | j保持加法与相反数直接按代表计算，不以单射冒充兼容性；整数副本省写范围明确。 |
| RA6逆元/消去 | 术语加法逆元先解释，唯一性只用此前的零、结合与已证相反数；加法消去包括共同加数零；和的相反数通过和为零及唯一性推出，不循环定义。 |
| RA7减法/方程 | 差定义为加相反数，整数分子ad−bc来自既有整数负号规则；x+r=s存在解s−r，代回与消去给唯一性，包括r零。 |
| 反例与界限 | 非零和为零由j(±1)；减法非结合由j(−1)≠j(1)；分子分母分别相加在换代表下输出2/5和3/7不同，反例确实击中代表无关。 |

同分母公式由((a+c)b,bb)与(a+c,b)的整数交叉积相等证明，未进行未经建立的Q乘法消去。一般分母bd是正共同倍数只用整数等式，不需要最小公倍数理论。全部正性声明明确针对整数分母。
