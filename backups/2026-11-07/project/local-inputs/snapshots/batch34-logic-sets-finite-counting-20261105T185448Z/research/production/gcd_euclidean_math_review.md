## 统一定义与证明链

| 对象 | 实际检查 |
|---|---|
| 定义 | 候选g非负、整除两输入，且每个整数公因数d都整除g；d包含负数与适用时的零。存在性证明前不默认每对输入都有gcd。 |
| G1唯一性 | 两候选互相整除，再用B1.10非负互整除则相等。只证至多一个，不预借存在性或通常大小最大。 |
| G2终点 | |a|非负，以1或−1见证整除a，以0见证整除0；任意d|a通过符号取反仍整除|a|。a=0时包括d=0，故gcd(0,0)=0合法。 |
| G3替换 | a=bq+r下，正向见证u−vq、反向见证vq+w；分配、结合及符号律逐行合法。d可以为零，且本命题不需余数界。 |
| G4终止 | 正第二输入时自然余数严格下降；初始第二项零立即停止。若执行v₀次仍未停，还能给下一步，产生v₀+1次下降，直接违反O11。每次内部自然除法另有有限操作证明。 |
| G5存在 | 先逐符号证明取绝对值保全部公因数，再对有限轮次归纳使用G3。终点(g,0)的自反及整除零给g为原公因数；任意原公因数也整除g，三条均建立。 |
| 双零及非零输出 | 双零初始即(0,0)，没有最后非零余数；其他输入若g=0，由0|a,b推出双零矛盾，因此g正。统一输出规则始终是终点第一项。 |
| G6全部公因数 | 正向定义，反向整除传递。非双零时公因数d整除非零g，幅值界给|d|≤g，由此才推出通常大小下最大正公因数。 |
| G7对称与变号 | 逐项保持全部公因数，再用候选性质和唯一性；同数输入候选|a|复用已有符号见证，包括a=0。 |
| 互素 | g=1给所有公因数整除1；反向以1作非负公因数候选并验证第三条，再由唯一性得g=1。±1确整除所有整数，故‘恰有±1’的说法有双向依据。 |

原始有符号输入到自然数状态的识别通过前文自然嵌入保持运算/次序，未直接把负数送入自然数除法。算法停止只需第二项严格下降，第一个数无需每轮下降或初始大于第二个数。G3保持目标与G4保证停止分别证明，不能互相替代。

## 发现并修复的问题

原G4写‘先前下降步数结论给出vᵢ+i≤v₀’，但B1.3 O11实际直接证明的是下降次数i≤v₀，未包含该加强终值不等式。加强式虽真，在此处没有证明就归给前文是不完整的依据。已向作者报告，最终稿删除加强式，改为再执行一步即超过O11步数上界的直接矛盾；复读后条件完整。

另外G1已改为直接引用非负互整除推出相等，避免省略从相伴取幅值的中间说明；互素判据反向已明确以1验证三条。两项精确化均已复查。当前没有待修数学问题。

## 实现与冻结验证

实际读取`integer_euclidean.py`、完整验证脚本及冻结JSON，核查源码哈希与当前文件相符，没有重新运行或刷新报告时间戳。输入验证拒绝布尔和非整数；带余除法拒绝零除数，负被除数区分大小余数零/非零，负除数只将商取反。整除的零左因子直接以右项是否零判定，避免调用除以零；其他因子以合法余数为零判定。欧几里得迭代只在第二项正时调用自然数除法，终点包括(0,0)。生产实现使用精确整数，未使用浮点。

独立比较模型分别为：Python对正幅值求余后精确求商；带独立零分支的Python模判断整除；最大公因数用正因子的有限穷举，未复用被测欧几里得迭代。分解输入范围−36至36、非零除数−12至12；整除与gcd两输入范围−36至36；公因数探测范围−36至36。冻结报告保存1752组除法、5329组整除、5329组gcd、16464行轨迹、1590889次公因数条件核对、67次非法输入拒绝及17个明确例。核对计数关系1752=73×24、5329=73²、公因数检查=73×(16464+5329)、拒绝=4×8×2+3，均相符；轨迹行数是本次运行实际汇总，未将它冒称为预先固定的全局界。

17个明确例包含超出网格的48/18、84/30及相应负输入和零边界；B1.9/B1.10其余书稿小输入处在网格范围。有限检查不能证明所有整数上的结论，公因数有限探测尤其不替代“对每个整数d”的数学证明。本报告未新增大规模测试、未保证资源效率或形式化验证。

`gcd_trace`记录替换前u,v,q,r，逐步更新(v,r)，没有在终点继续除零；`gcd_integer`只取同一输出值。验证检查每行分解、余数界、状态连接、轮数≤|b|及终点(g,0)，并用独立有限因子搜索比较结果；非零初始之外也包含初始终点的双零情形。泛性质对无限整数d的证明仍由G3、G5、G6承担，不能由有限探测替代。
