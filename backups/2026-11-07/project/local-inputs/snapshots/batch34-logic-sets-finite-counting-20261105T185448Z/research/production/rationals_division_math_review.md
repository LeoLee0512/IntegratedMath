## 全称证明与定义域

| 项目 | 独立检查结论 |
|---|---|
| RD1非零与零无逆 | r非零 iff 任意合法代表分子非零来自R4双向；零乘任意数仍零且0≠1，故零没有逆元。 |
| RD2唯一 | u=u1=u(rv)=(ur)v=1v=v，只调用B1.16单位/结合/交换，尚不使用倒数函数或除法。 |
| RD3存在 | a非零，按整数三歧分a正/负；分别取(b,a)或(-b,-a)，正分母逐项核实。乘积两分量相同，交叉判据识别一。 |
| RD3代表无关 | 任何另一代表同样构造乘回r为一的候选，再由已证RD2识别类。没有假定倒数先已良定义。 |
| RD3后续规则 | 倒数为零将使积零矛盾；逆的逆和一的逆由唯一性；-r非零先由双取反证明，再用两相反数乘法及唯一性推出取负公式。 |
| RD4除法/方程 | r/s只对s非零定义。sx=r有唯一解rs逆，存在代回、唯一性乘s逆均合法；双零方程全部Q为解、零系数非零目标无解。没有给0/0任意指定一个解冒充商。 |
| RD5旧记号兼容 | 整数b非零使j(b)非零；b正取(1,b)，b负取(-1,-b)，乘j(a)分别输出(a,b)/(-a,-b)，吻合此前两分支书写定义，含a0。 |
| RD6零与负号 | 非零除数前提保留，商零iff被除数零用已证乘回式；涉及-s先证其非零。除一、自除及同除数分配均在合法域，零被除数允许。 |
| RD7约因子 | s,t非零先由零积保证ts非零；r/s是(ts)y=tr的解，再唯一性得等式。r可为零，t零会产生未定义0/0，不可约。 |

删加项反例(1+1)/(2+1)=2/3而1/2不同，交叉积4≠3；连续除法反例(1/2)/3=1/6而1/(2/3)=3/2，所有除数非零，交叉积2≠18。一般合法除法不等于任意括号都相同。

正文负分子例仅核查负分支，已将说明改为准确范围；正分支的一般存在证明已独立完成。外部源码的零逆元总函数约定不被移入书稿，最后来源说明与本书部分定义一致。
