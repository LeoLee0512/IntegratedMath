| 对象 | 实际检查及结论 |
|---|---|
| 对象与闭合 | a,b,c,d等均为自然数分量，x,y,z为整数类。候选F((a,b),(c,d))=(ac+bd,ad+bc)的两分量为自然数，先在对上规定计算，再证明可以用于类。 |
| M1第一输入替换 | a+b′=b+a′。输出交叉和P+Q′重排为(a+b′)c+(b+a′)d；用给定自然数等式替换，再展开重排为Q+P′。每步只用自然数分配、交换、结合。 |
| M1第二输入与同时替换 | F(A,C)=F(C,A)是自然对逐分量恒等式，先用它移换输入位置再调用第一步，最后用等价传递处理两代表同时替换。没有先用尚未定义的整数乘法交换律。 |
| M2零、一、嵌入和交换 | 直接使用(0,0)、(1,0)、(m,0)、(n,0)计算；交换由M1自然对恒等式转移到类。保留自然数乘法是新定理，不是混同底层对象。 |
| M3结合 | 两次乘法的每个坐标分别展开为四个自然数三因子项。左第一坐标次序ace、bde、adf、bcf，右次序ace、adf、bcf、bde；第二坐标同样按所列置换吻合。逐项使用自然结合及有限加项交换，不循环借整数结合。 |
| M4分配 | 加法定义使右因子代表为(c+e,d+f)，两个坐标自然展开后分别匹配两个乘积的逐坐标和。另一侧分配在此后才用已证交换律推出。 |
| M5符号 | 已证y+(−y)=0，分配及零积表明x(−y)与xy之和为零，再由B1.7逆元唯一得到负号规则。换左因子用已证交换，双取反用B1.7双重相反数。包括零，没有偷换成严格正负结论。 |
