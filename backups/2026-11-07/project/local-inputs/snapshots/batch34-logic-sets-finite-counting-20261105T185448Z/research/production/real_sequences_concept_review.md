## SL1—4 的量词与索引核查

N={0,1,…} 与 Lebl 原文从 1 开始不同，原文的 1/n 不能直接搬入本书全 N 定义。计划使用 1/(ν(n)+1) 正确，n=0 时值为 1，分母始终正。下标 n 和实数 ν(n) 保留类型区别；允许清楚宣布简写后再省 ν，不可悄然混用。

SL1 收敛是 ∀ε>0 ∃N∈N ∀n∈N（n≥N ⇒ |a_n−L|<ε），N 可依赖 ε、给定列及 L，不能依赖其后的 n。固定 L 的否定为 ∃ε0>0 ∀N∃n≥N，使误差≥ε0；无实数极限还需对每个 L 都否定。若讨论弱误差版本，强⇒弱直接；弱⇒强对 ε/2 用弱定义，再由 ε/2<ε 得严格界。不要称所有 ε 共用一个 N 为必要条件，常数列却确实可以如此。

SL2 δ=|L−M|>0；3 是正实数，δ/3>0。自然 max 必须定义两支且证同时≥两阈值。可直接令 n 为 max，故不是偷偷假定共同尾部非空。展开 L−M=(L−a_n)+(a_n−M) 后三角得 δ<2δ/3；由正数 δ 及 2/3<1 得 2δ/3<δ。不存在未建极限函数先行。

SL3 先证 ε>0 的倒数正；RA1 选正 N 使 1/ε<ν(N)。n≥N⇒ν(n)+1≥ν(N)+1>1/ε，由实数正倒数反序及双倒数得 0<b_n<ε。指定 ε=1/10 时最早合法 N=10，ε=1/100 时 N=100；一般正整数 q 的 ε=1/q，严格误差要求 n+1>q，等价 n≥q。N=q 足够；任意 N<q 时 n=q−1≥N 且误差恰为 1/q，故更早阈值失败。这里只在 q≥1 时使用 q−1。

SL4 最终相同的双向证明各取 max(Nε,N0)。固定 k 尾移的反向由 m≥N+k 得 k≤m，存在 n=m−k，且 n+k=m；序反映给 n≥N。k=0、N=0 无异常，建议在本批保留此短双向证明，不因篇幅推迟。余数定义交替列每个尾部均有 2N、2N+1，二者≥N 用自然加法见证；由商余唯一核对应值确为 0、1。假定存在任意 L，用 ε=1/3，同一阈值下两个误差相加给 1<2/3，矛盾。无需实数幂或子列定理。

有限前缀反例建议明说“前 K 项”是 0≤n<K：a_n恒0，b_n在 n<K 为0、n≥K 为1。K=0 时前缀为空仍有两种不同全函数。题8“项变小所以趋零”可用 1+1/(ν(n)+1)，严格递减由正倒数反序逐项证，却趋1；“每个尾部只找到一项”可用交替列的偶项，不能将存在 n 替换全部 n。

## SA1—4 的条件与估计核查

SA1 固定状态递归补齐后，归纳性质为 B_k≥0 且对所有 i<k 有 |a_i|≤B_k。k=0 是空条件；归纳步用 i<k+1⇒i<k 或 i=k，再分别用旧界或新项界，max 两支都满足。ε=1 给尾部界，M=max(B_N,1+|A|) 非负且覆盖全部自然指标，包括 N=0。不能引用尚未写的有限集合最大值定理。

SA2 加法取 ε/2，正分母 2 先核；常数倍 c=0 单列，c≠0 时 |c|>0，按 ε/|c| 选阈值。严格乘回只用正 |c|；差由 −1 倍加和；绝对值列由反三角 ≤ 原误差 <ε。各组合先是 N→R 的全函数。

SA3 K=M+|B|+1>0，且 M≤K、|B|≤K。δ=ε/(2K)>0 且 Kδ=ε/2，必须由乘回/消去说明，不能靠未证明的分式口诀。分解 a_nb_n−AB=a_n(b_n−B)+B(a_n−A) 逐次分配消去。对 e=|b_n−B|≥0，|a_n|e≤Me≤Ke<Kδ；此处严格步来自 K>0 和 e<δ，故 M=0 仍正确。另一项同理。两项相加 <ε，不能写“乘以 M 严格保序”而漏 M=0。若收有界列×零极限的加强推论，必须另给 K=M+1 与 ε/K 的估计，不引用需要 a_n 收敛的 SA3。

SA4 记 β=|B|>0。先在阈值 N0 后令 e=|b_n−B|<β/2；由 β−|b_n|≤e 推 |b_n|>β/2>0，故只证明最终非零。若要 c_n=1/b_n 为全列，必须所有 b_n 非零；若有早期零，则定义 c_n在 n<N0 任取实值、n≥N0 才取倒数。证明这个已定义全列的极限后，才用有限改动证明其他早期选择给同一极限，不能对未定义的“原倒数列”调用有限改动。

倒数差可先验证 (b_nB)(1/b_n−1/B)=B−b_n；b_n、B、乘积均非零，解的唯一性给差的分式式，再取绝对值。令 D=|b_n|β、D0=β²/2，均正，D>D0。为覆盖 e=0，安全估计是 e/D≤e/D0<ε，后者来自 e<εD0；不可声称 D>D0 使 e/D<e/D0 对零 e 也严格。分式比较和乘回的每步由正除数说明。阈值取下界阈值与误差阈值之 max。A/B 合法由 B≠0；全商列或早期补值列的类型分别声明。

B=0 的反例分清两种逻辑：b_n=1/(ν(n)+1) 趋零、全项非零；倒数列为 ν(n)+1，若收敛则 SA1 有界，RA1 取 ν(n)>界即可矛盾。但是 a_n=b_n 的商恒1，故零分母极限不意味着每个商发散。最后计算题逐 n 先验 ν(n)+1>0，乘回核 (2ν(n)+3)/(ν(n)+1)=2+1/(ν(n)+1)，再用 SL3/SA2；不需要商极限定理，也不误把无界分子分母分别取有限极限。
