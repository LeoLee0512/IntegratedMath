## IV1 的逐步数学检查

1. **定义与目标。** 闭区间明确要求实数端点 a≤b；a=b 给单点域。端值的 min/max 仅是全序下两个实数的比较，不偷用全域极值存在。命题只保证端点输出之间的值属于实际像，不保证根唯一或实际像恰为端值区间。
2. **上确界见证规则。** 非空有上界的 S 已满足 DC4 条件。若无 s>c−h，则 c−h 为上界，最小上界性推出 h≤0，与 h>0 矛盾；s≤c 来自上界性。没有预设 c∈S。例 S=[0,1) 对 u<0 与 0≤u<1 分支给合法成员，确实证明 sup S=1 且 1∉S。
3. **严格端值的准备。** f(a)<y<f(b) 排除 a=b；S={x∈[a,b]:f(x)≤y} 含 a 且以 b 为上界。由上确界性质先得 a≤c≤b，故 f(c) 和在 c 的连续性已经合法。
4. **第一步 c>a。** 正输出间隙给正误差；t=min(δ/2,(b−a)/2)>0，保证 a<x=a+t<b 且 |x−a|<δ。误差界推出 f(x)<y，因而 x∈S、c≥x>a。没有假设 f 在区间单调。
5. **第二步 c<b。** u=b−min(δ/2,(b−a)/2) 严格位于区间。对每个域内 x>u，0≤b−x<t<δ，连续性强制 f(x)>y；所以 S 的每个成员≤u，u 确为上界，得 c≤u<b。仅有 b∉S 不足推出 c<b，稿件没有犯这一错误。
6. **第三步排除 f(c)<y。** 正半径同时控制输出误差和右端剩余长度，构造合法 x=c+t∈(c,b)，再证明 x∈S，与 c 为上界矛盾。这里右侧点存在来自实数有序域的正半距构造，不依赖图像、稠密有理点或单调性。
7. **第四步排除 f(c)>y。** h=min(δ/2,(c−a)/2)>0，见证规则给 s∈S 且 c−h<s≤c；于是 |s−c|<δ。连续性给 f(s)>y，与成员定义矛盾。允许 s=c 完全合法，因为连续条件不去心；没有误用要求非中心输入的极限定义。
8. **分支穷尽。** 全序排除两个严格不等式后得到 f(c)=y。等于端点值时直接取对应端点；相等端值与 a=b 的情形被覆盖。反向严格端值对同域 g=−f 用 CT3 系数 −1 得连续，端值取反反序后调用已证正向情形，再取反还原。不存在把目标结论用于证明同一情形的循环。
