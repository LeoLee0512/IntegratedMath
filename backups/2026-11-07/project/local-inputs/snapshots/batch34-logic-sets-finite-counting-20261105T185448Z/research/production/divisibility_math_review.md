## 定义和证明

| 项目 | 实际检查 |
|---|---|
| V1定义与见证 | a|b只要求存在整数k使b=ak，包括a=b=0；非零a时见证唯一来自非零消去，零情形不宣称唯一或可除以零。 |
| V2传递/线性组合 | 见证分别为kl与sk+tl，全部自然/整数对象所在层级清楚；符号改变逐项给−k或k，两个反向用双重取反。整除乘积的单向推论未误当双向。 |
| V3零 | a|0用见证0，0|b推出b=0，反向也给见证；不把带余除法的禁止零除数移植到整除关系。 |
| V4幅值事实 | 正整数来自正自然数，后继比较给至少一。幅值乘法先证非负性，再由四种符号给xy=±mn，最后用幅值唯一性；零时形式重复不影响证明。 |
| V5单位 | uv=1先排除零，m=|u|、n=|v|正且≥1；mn=1与正乘法保序给m≤1，反对称得m=1。充分性显式给±1见证，无分数逆元先修。 |
| V6幅值界 | b=dk且b非零先排除d,k为零；|k|≥1和|b|=|d||k|给0<|d|≤|b|。零目标反例和带符号大小反例均准确。 |
| V7互整除 | a=0直接由0|b得b=0；a≠0用双见证得a=a(kl)，消去后kl=1，单位判定给k=±1。反向分别给1或−1见证。非负子范围再排除不等的相反数。 |
| V8余数判别 | d>0，余数零直接给整除见证；若整除，(k,0)满足严格余数界，再用B1.9唯一性识别r=0。不仅凭dq+r=dk目测余数。 |

## 八题答案

| 题 | 核查结果 |
|---|---|
| 1 | 真者见证分别−4、−3、任意整数、0；0|5由零积否定，4|6由非零余数否定。只0|0见证不唯一。 |
| 2 | 三种变号见证−k、−k、k，含零；否定等价的两个方向分别反证，未由有限试算排除见证。 |
| 3 | a|2b−3c见证2k−3kl；(3,1,2)反例用幅值界否定分别整除两个加数。 |
| 4 | 两方向见证k+t、l−t，d=0两侧都等价于a=0。没有消去d。 |
| 5 | 全称整除取目标1得单位；±1对任意目标给见证，零由目标1排除。 |
| 6 | 非零目标6的幅值界先缩至±1…±6，后继比较解释清单穷尽；1/2/3/6给见证，4/5用合法非零余数排除，符号等价完成负数。目标零的无限因子范围单独说明。 |
| 7 | 相伴给同幅值，2与−2反驳必相等；非负范围排除非零相反，已知a=0直接用乘零求b，不消零因子。 |
| 8 | −20/4余数0，−21/4余数3；加dt保余数通过合法分解和唯一性。题4含零/负因子，余数论证只使用d>0，范围区别明确。 |

正文此前提到的6|2·3但6不整除2，后续确以幅值界给出不存在整数见证的理由，不把尚待证明的直觉充作证据。答案的六之因子清单没有借素因数分解。

## 实现及现有有限验证

实际读取`integer_euclidean.py`、完整验证脚本及冻结JSON，核查源码哈希与当前文件相符，没有重新运行或刷新报告时间戳。输入验证拒绝布尔和非整数；带余除法拒绝零除数，负被除数区分大小余数零/非零，负除数只将商取反。整除的零左因子直接以右项是否零判定，避免调用除以零；其他因子以合法余数为零判定。欧几里得迭代只在第二项正时调用自然数除法，终点包括(0,0)。生产实现使用精确整数，未使用浮点。

独立比较模型分别为：Python对正幅值求余后精确求商；带独立零分支的Python模判断整除；最大公因数用正因子的有限穷举，未复用被测欧几里得迭代。分解输入范围−36至36、非零除数−12至12；整除与gcd两输入范围−36至36；公因数探测范围−36至36。冻结报告保存1752组除法、5329组整除、5329组gcd、16464行轨迹、1590889次公因数条件核对、67次非法输入拒绝及17个明确例。核对计数关系1752=73×24、5329=73²、公因数检查=73×(16464+5329)、拒绝=4×8×2+3，均相符；轨迹行数是本次运行实际汇总，未将它冒称为预先固定的全局界。
