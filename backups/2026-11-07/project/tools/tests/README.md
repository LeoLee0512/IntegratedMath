# 第一部分验收器回归测试

在仓库根目录运行：

```bash
python -m unittest discover -s tools/tests -p 'test_*.py' -v
```

依赖为`requirements-build.txt`中的PyMuPDF与Pillow；测试框架使用Python标准库`unittest`。也可从其他工作目录直接执行本目录的`test_part1_acceptance.py`，仓库根目录由测试文件位置确定，不依赖固定工作区路径。

共21项测试：19个验收器来源关卡场景，加2个既存真实Crossref证据的限定内容场景。覆盖完整证据、缺来源记录、缺来源要求、G以通用逻辑替代专题、HTTP成功但未审读、内容哈希不一致、访问记录冒充内容审读、缺具体定位、待核状态、目标覆盖错配、被阻断来源、缺节、原创T/S豁免、G不能豁免、外引事实不能冒称原创、混合S目标，以及独立数学审阅仍不可缺少。负例同时确认无关的数学、教学、构建、视觉关卡仍通过，并检查预期阻断理由，防止测试因其他意外失败而误报成功。

每项测试在独立的`TemporaryDirectory`中构造并清理数据、PDF、图片与压缩包，不重建教材、不写仓库验收回执、不运行历史临时脚本、不联网。完整通过的fixture包含明确标为虚构的来源证据；不会把缺来源的旧baseline直接当作accepted执行。真实Crossref测试仅复制并读取仓库既存核验记录：角色字段内容记录可通过，而它不能满足数学哲学专题要求；这不等于整节或全部分完成，也不代表再次联网核验了原站。

2026-11-05整理并执行：21项通过。此结果是验收器回归检查，不是书稿数学、来源内容或视觉验收结论。
