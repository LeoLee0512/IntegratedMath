## 全称证明与条件检查

| 项目 | 审查内容与结论 |
|---|---|
| 输入域和集合背景 | P仅包含整数a与正整数b；明确与旧整数构造的P不同。类是子集，Q为类集合，采用的朴素集合背景已明示，不冒称公理集合论全部构造。 |
| R1等价关系 | 自反/对称均由整数乘法。传递中从ad=bc、cf=de推d(af)=d(be)，消去的是中间正分母d；未要求任何分子非零，未用有理数除法。 |
| 删条件反例 | (1,1)与(0,0)、(0,0)与(2,1)分别交叉等价但端点不等价，正确说明扩大域会丢失传递性。 |
| R2类相等 | 等价推出两个包含方向分别用对称/传递；类相等推出等价用p∈[p]及类定义。共享代表则类相同亦已证；代表逐项相等与类相等未混淆。 |
| 类记号 | a/b此时只命名等价类；正缩放保持类由整数交叉积证明，零缩放非法。没有暗借分数约分、除法或有理数大小。 |
| R3整数嵌入 | j(n)=[(n,1)]合法；交叉判据直接推出双向单射判据。零和一不同；尚未宣称运算兼容。 |
| R4零类 | 合法代表等于[(0,1)] iff a·1=b·0 iff a=0，含任意正分母。 |
| R5存在 | 先用C5得到g>0与整数见证a=gA、b=gB、B>0及互素；再独立验aB=bA，才确认提取对属于原类。 |
| R5唯一 | R2得AD=BC，B、D正且两对互素满足C6全部前提；C6取消正第二分量，不取消可能为零的分子。零规范对(0,1)、整数副本(n,1)均另验gcd条件。 |
| 规范条件反例 | (1,2)/(2,4)针对去互素；(1,2)/(-1,-2)明确发生在扩大记录域，第二对不是当前P代表；类有不同元素与唯一规范代表不矛盾。 |
| 负分母记号 | b≠0的两分支由整数三歧性覆盖且互斥；b<0时取(-a,-b)确实正分母。所有负号只在整数分量上，0/0和a/0没有定义。 |

证明依赖方向为整数运算及非零消去→新关系→类相等→嵌入/零→使用已证C5/C6的规范化。C5/C6在整数中独立证明，不反向依赖本单元有理数，故无循环。
