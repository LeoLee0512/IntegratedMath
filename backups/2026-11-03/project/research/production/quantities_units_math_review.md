## 模型和一般换算证明

| 项目 | 实际检查 |
|---|---|
| 量模型 | 固定类别和参考单位u，xu为记录记号，xu=x′u iff系数相同；u不是未指定有理数，跨类别不由相同数字识别。单写u、v、w分别约定为1u、1v、1w。 |
| 符号范围 | 允许任意有理系数描述带符号模型；无向长度、路程、历时例取非负，速率分母历时严格正。没有把负物品/负路程当普通物理输入。 |
| 新单位/加法 | k正、v=ku时定义yv=(yk)u；同类量加法先在u上定义，新单位加法显式转回u并分配得(y+y′)v，未另造冲突运算。 |
| QU1唯一 | xu=yv等价x=yk，k正故非零，以既有乘法方程证明y=x/k存在唯一；不是在未定义量乘法中约去u。零、非负/正保留及比较由正逆倍率证明。 |
| 非正倍率边界 | k0使所有记录化零，非零量无表示、零量不唯一；k负纯代数仍唯一但反序，不符合正单位模型约定。 |
| QU2往返 | u=(1/k)v且1/k正，二次换算的候选原x满足方程z(1/k)=x/k，唯一性得回原值。 |
| QU2复合/和 | w=lv=(lk)u，lk正；z(lk)=(zl)k=yk=x，唯一性使两次同直接。相加后换单位以pk=x+z与唯一性核一致。 |
| QU3同类比 | 两量必须先同类别/同单位且第二数值z非零；换算z′非零单独证明，利用(pz′)k=x′k消非零k，再以z′非零方程唯一解得比不变。 |
| 单位商约定 | 路程x≥0、历时z>0，率数值x/z；u/τ是速率类别标记，不是两个有理数相除。新单位商v/w=(k/l)(u/τ)作为明确模型约定。 |
| QU4数值 | k,l,z正保证所有除法及新单位合法。q=(l/k)(x/z)，逐因子写为逆元并消ll逆，得q(z/l)=x/k，唯一性给新率数值。 |
| QU4记录 | 再展开q(k/l)的两个逆元对得旧p，证明新率记录与旧记录同一。倍率k/l与数值倍率l/k方向相反，非凭单位名称划约。 |

明确区分平均速率的路程/历时与需方向的平均速度，没有从平均值推出逐秒恒定。零路程正历时合法为零，零历时下正路程无解、零路程所有数皆解，均未定义平均速率。量纲只作较粗结构说明，不把同量纲当作同类别相加许可；偏移刻度、测量误差、实数连续模型与正式函数定义均留后文。

正文精确单位关系cm=(1/100)m、km=1000m、h=3600s作为外部约定而非数学公理结论。3/2米对应150厘米及3/2000千米；1米+1厘米为101/100米；2米与50厘米比4。速率示例15/2千米、3/2小时得5千米/小时；转7500米、5400秒得25/18米/秒，交叉135000正确；单位商转换5/18乘原数值5一致。新增新单位加法及QU4逐项倒数展开已经实际复核。

## 精确数值代码与有限验证

实际读取完整`ratios_units.py`及验证脚本，最终29例报告的七份源码哈希均与当前文件逐一核对。未重跑验证或刷新时间。冻结报告时间2026-10-27T17:11:44.502748+00:00，状态passed。

`ratio`调用既有精确有理除法，后项类为零时拒绝，负后项允许。`proportion`在计算交叉乘积之前检查两比分母的整数分子非零，再比较ad与bc的有理类，故不会由零交叉乘积给未定义比例赋真值。`positive_scale`先核记录合法，再要求其整数分子严格正；正分母下这等价于倍率为正。`convert_value`返回x/k；`convert_rate`返回xl/k，k对应新分子单位在旧分子单位中的倍率、l对应新分母单位的倍率。输出均规范化。

换算内核接收数值而非带类别的量，不推断量类别、单位关系、物理合法性或测量精度。数值可为负或零以支持带符号代数记录；平均速率应用还须由调用方保证非负路程及正历时。单位倍率不能非正；不支持仿射刻度。书稿明确模型要求，代码文档也明示调用方职责，未把仅检查正倍率误称为量纲系统验证。没有分配算法API，分配结论由数学稿证明。

独立参考为Fraction，全部精确整数/有理计算，不用浮点。主记录分子−3至3、分母1至3，共21份，其中非零18份、零3份；总441对比值输入中378合法、63次零后项拒绝。比例小网格分子−1至1、分母1至2，共6份，其中非零4份；1296个四元组中576满足两个后项非零，720次拒绝。正倍率网格分子1至3、分母1至2，共6份。

21×6=126组换算往返同时核数值与倍率正缩放的代表独立性；与比值的378次换代表合计504次。21×6×6=756组复合转换比较先除k再除l与直接除kl；相同756组率转换与Fraction的xl/k比较，并用k逆、l逆核往返。12类非法记录在ratio两位、proportion四位、convert_value两位、convert_rate三位，共12×11=132次拒绝；零和两个负倍率各在三个倍率参数位测试，共9次非正倍率拒绝。独立按循环复算378=21×18、63=21×3、576=6×4×6×4、720=6⁴−576、504=378+126，其余计数与报告一致。
