## 构建与检查

安装 `requirements-build.txt` 中的 Python 依赖。系统需有 pandoc、XeLaTeX、poppler-utils，以及 Noto CJK、DejaVu 字体和 fvextra、newunicodechar 等TeX包。

```sh
python -m pip install -r requirements-build.txt
python tools/build_learning_batch.py
python tools/validate_learning_batch.py
python tools/build_production_ledger.py
```

干净检出无需预先存在 `dist/`、`build/` 或图片；样式源位于 `tools/style.css`，图片由代码重建。没有原始MSC PDF时，目录生成器使用经完整性校验的 `data/catalog_titles.json`；英文对照、中文标题与归属保存在 `data/catalog_titles_zh.json`。

本批构建器先重建并验证第一章独立稿，再生成包含六十三个基础单元的综合稿。当前本批入口为 `build_learning_batch.py`，核验报告为 `data/production/batch_validation.json`；旧 `package_ch01_review.py` 只适用于第一章单独构建，不能用来包装扩展后的综合稿。自动生成截图不等于已看过，程序通过也不是全书形式化验证。现有 CI 仍只检查第一章构建，新批需运行上述本地命令和实际视觉检查。

本地生成的阅读文件是 `dist/综合数学_基础续写审阅版.md/.pdf/.html`（本批正文）和 `dist/综合数学.md/.pdf/.html`（含全目录）。伴生包的本地打包说明和本批结果见 `BATCH_CHECKPOINT.md`。所有后续上传仍是单独操作，本轮没有执行。
