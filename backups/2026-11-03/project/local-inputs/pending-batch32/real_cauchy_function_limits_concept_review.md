## 2. CA1—CA4：非循环的柯西路线

CA1 的量词是先给任意正实误差，再选一个自然阈值，最后控制所有两个尾部指标。完整否定保留同一个正误差，在每个尾部找到一对误差不小于它的项。对角线恒有零误差不能检验柯西；相邻项控制也不等同于所有两指标控制。计划不在本批强行引入未证明的调和级数反例，容量合理。

CA2 的收敛蕴含柯西以同一误差 $\varepsilon/2$ 控制两个输入，通过三角合成。柯西蕴含有界的独立证明以误差一取 $N$，固定第二指标为合法尾部指标 $N$，得全部 $n\ge N$ 的
\[
|a_n|\le |a_n-a_N|+|a_N|<1+|a_N|.
\]
前缀界取自适用于任意列的递归过程，再取两个实数的较大者覆盖所有指标。$N=0$ 时前缀为空、$U_0=0$，证明照常成立。这一路线没有先把柯西列判为收敛再取界。

CA3 的关键是固定一次子列位置。对误差 $\varepsilon>0$，柯西阈值为 $N$，子列趋 $L$ 的阈值为 $J$，固定
\[
j=\max_{\mathbb N}(N,J).
\]
SS1给 $k_j\ge j\ge N$。于是任意 $n\ge N$ 都能与同一个 $a_{k_j}$ 比较，并有
\[
|a_n-L|\le |a_n-a_{k_j}|+|a_{k_j}-L|<\varepsilon.
\]
$j$ 可依赖误差，但不依赖后任取的 $n$；两个三角项的指标条件没有遗漏。即使某个误差为零，仍合法地小于正半误差。

CA4 才按“柯西有界→BW给一个收敛子列→CA3控制全列”完成充分性，与 CA2 必要性合成判据。到此才可使用实数数列的柯西完备性名称。最终相同的柯西性双向由共同尾部直接证明，须保持两数列都是全函数。

八题设计能分别检验量词、两个直接例、必要性、非循环前缀界、固定子列项、BW充分性、最终相同及删去柯西条件的交替反例。最后的交替列有界且有收敛子列而非柯西，正好说明 CA3 的核心假设不可遗漏。

## 3. FL1—FL3：聚点、唯一性和局部条件

FL1 要求 $D\subseteq\mathbb R$、$p\in\mathbb R$，聚点条件为每个正半径内都有某个域内非中心输入。$p$ 可以不在域中，域非空不足以替代聚点。$\mathbb R$ 与 $\mathbb R\setminus\{p\}$ 的见证 $p+r/2$ 同时保证属于域、不同于中心及距离小于半径。半线例可只说明域限制，不必另展开左右极限体系。

函数极限定义及其固定候选 $L$ 的完整否定均正确。对孤立域 $\{p\}$，穿孔条件无满足者，裸误差条件会对每个候选成立；这不是给孤立点定义多个真正极限，而是解释为什么本书预先要求聚点。

FL2 必须对两个正半径定义较小者并证明仍正，再由聚点取得一个实际同时满足两份条件的输入。反证距离 $\lvert L-M\rvert$ 的正三等分路线完整。常数函数、恒等函数及仿射函数的直接估计可用同一任意聚点域；零系数分支误差恒零，不得通过除以系数处理。

FL3 同域局部相等的两方向各取共同正半径；如果只改中心值，须先有 $p\in D$，否则不使用不存在的 $f(p)$。局部有界结论仅控制穿孔邻域，不控制整个域，也不控制中心值。极限 $B\ne0$ 的非零下界由反三角得 $|g(x)|>|B|/2>0$，同样只在所选穿孔近域成立。这些条件是后续商的域证明所需，不能扩大成全域非零。

固定共同域 $D$ 和同一聚点 $p$，先定义逐点和、常数倍、差、绝对值及积的合法实数函数。数列定理不能直接充作函数定理；本计划要求重新写出全称穿孔输入下的误差链，这是正确安排。

若 $B\ne0$，定义
\[
D_g=\{x\in D:g(x)\ne0\}.
\]
商函数只在 $D_g$ 上定义。先取正半径 $r_0$，使 $D$ 的穿孔 $r_0$ 近域全部属于 $D_g$。任给 $r>0$，聚点条件在 $\min(r,r_0)>0$ 内提供一个实际输入，它属于 $D_g$，且与 $p$ 的距离在 $(0,r)$。故 $p$ 是 $D_g$ 的聚点，商的极限定义至此才满足输入前提。允许 $g(p)=0$ 或 $p\notin D$，不会把穿孔条件误扩到中心。

倒数误差先逐乘回证明分式等式。令 $h=|B|>0$、$d=(h/2)h>0$，在近域 $Q=|g(x)|h>d$。再取得分子误差 $e=|g(x)-B|<\varepsilon d$ 的半径，正确链是
\[
\frac eQ\le\frac ed<\varepsilon.
\]
第一步必须是弱比较，因为 $e=0$ 时两商同时为零；第二步由正分母和给定严格分子界得到。不得写 $e/Q<e/d$ 后不处理零分子。

把 $f$ 限制到 $D_g$，应由域包含和原穿孔定义直接证明仍趋 $A$；由于 $p$ 已证是该子域聚点，才能在这一共同域应用刚证乘积定理得商趋 $A/B$。不需要假定 $D_g=D$，也不需要往未定义的零分母处填值。

题8的差平方商在 $\mathbb R\setminus\{p\}$ 上有非零分母，先在实数域内展开并乘回得到 $x+p$，再直接控制与 $2p$ 的误差。$f=g=x$、$p=0$ 的零极限分母例说明 $B=0$ 仅表示商定理不适用，不表示商必无极限。这一比较不会循环引用一般有理函数连续性。
