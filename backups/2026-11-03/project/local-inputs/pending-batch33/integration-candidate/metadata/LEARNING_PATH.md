# 《综合数学》学习路径与开写顺序

MSC 目录负责找到主题；本文件负责回答“先学什么”。编号顺序不要求读者从第1章一直顺读到第534章。下面 B0—B6 是学习阶段名，不新增 MSC 章号，也不意味着对应教材已经完成。当前可读入口为 B0 第1章、B1.1—B1.21、B2.1—B2.38 与 B4.1—B4.8，共六十七个基础桥接单元。B1 从自然数推进至有理运算、比与单位；B2 先写函数、有理方程与坐标、幂与多项式，再从有理缺口构造分割实数、有序域、阿基米德性质、有理像稠密与非负平方根，再接实数绝对值、线距、实数二次方程、实坐标平面与欧氏距离，再证直线交会和正交投影最近点。B4另由已写实数、函数与自然规则进入数列收敛和四则极限，再接比较夹逼、单调收敛、确定性单调子列、实数数列BW与柯西判据，再切换第18部分第146章26A03的直接函数点极限；B4.6不以柯西判据为逻辑先修，B4.7—B4.8再以直接连续与一个上确界建立区间介值，不借数列子列路线，也不把平面几何设为先修。实际审阅、构建和页面验收以绑定当前文件的报告为准；其余 B1/B2 目标、B3形式基础、B4其余目标及B5—B6深造支线仍待写，尚无整章或整部分完成。

基础干线里的具体概念必须逐步建立。阶段名和“掌握分析”不能代替章首的具体先修清单；开始某个模块时，把上表落实为已写出的章、节、命题锚点和可检查的练习。已经会相关内容的读者可用入口练习跳过重复学习；不认识所用符号的读者沿先修链接回到首次定义。

01类数学史、97类数学教育，以及各部分的通用文献类型可按兴趣穿插阅读，不是计算和证明的强制先修。其余63大类中的应用领域按所需数学支线进入，不因在 MSC 中排得靠后就要求读完此前所有部分。

## 第1章到第2章的衔接

第1章的数值运算用于学习按明确规则核查论证，并不等于B1—B5已经完成。B1.1—B1.19在第26章逐步建立自然数、整数和有理数运算，B1.20—B1.21在第526章接比与单位；函数及有理坐标接第529章，有理代数接第528章，实数支线B2.21—B2.33再续第526章至非负平方根与实数线距，B2.34再回第528章建立实数二次方程。各单元只承担所列目标，不新增MSC章号；素数、唯一分解与同余等支线仍待写，几何模型另由B2.35—B2.38建立，实数数列极限入口另由B4.1—B4.2建立，均未由算术单元自动取得。精确依赖和当时的课程交接见[有理数开写交接](research/production/rational_handoff.md)，当前进度以本文件开篇及各单元实际证据为准。

目录中的第2章是 00Bxx“会议论文集与文章汇编”，属于文献定位。开写建议为 G 级，依赖第2、8、9节的文献阅读方法，说明各类文集的用途、检索方式和核验边界；它不承担从小学算术直接过渡到高等数学的职责。此处只有编写计划，第2章正文仍未开始。

未来每章开写前依次检查：目标是否明确 → 先修是否已写并可读 → 是否存在循环依赖 → 每节采用什么深度 → 篇幅是否需分单元 → 读完后走向哪里。先修未齐的教学内容保留待写状态，不用研究术语把缺口盖过去。

## 有理数基础之后的下一步

先在已经建立的有理数范围内教比与比例：作为商的比必须标明后项非零；比例交叉乘积的等价变形逐个核对分母条件。随后解释量、数值与单位，换算因子的方向、量纲和精确有理倍率。它们的先修为B1.14—B1.19，不依赖这些早期有理单元之后才建立的实数完备性。

函数入口先用明确的有理数定义域与值域，区分输入、规则、输出和图上的有限取点，再进入坐标与初等图形。真实测量的不确定性与理想精确数量需要分开说明。本段早期有理函数接口不以实数为前提；后续B2.21—B2.32已另行承担实数构造、上确界完备性和平方根证明。无理长度的几何解释及连续函数图像仍是独立待写目标，不能从有限有理刻度示意图获得。广义“比例与单位”“函数”模块内其余目标的先修在开写时继续展开。

B2.7[一次不等式与有理区间](manuscript/foundations/linear_inequalities.md)、B2.8[绝对值条件与有理距离](manuscript/foundations/absolute_inequalities.md)已保存，各有八题独立全解，当前验收依台账。下一批接有理坐标与仿射图像，从有序对及函数图出发，逐步证明斜率、截距、单调性和交点的代数对应。坐标里的连续实数背景和几何公理另行建立，不默认有理平面已含所有实际点。

## 有理坐标之后的代数准备

B2.9[有理坐标与函数图](manuscript/foundations/rational_coordinates.md)、B2.10[仿射图像与方程交点](manuscript/foundations/affine_graphs.md)均回到第529章97I20，新增正文与独立八题答案以实际哈希审查状态为准。点是Q²中的有序对，斜率是非零输入差下的差商，交点通过共同方程证明；没有建立实坐标平面或几何长度。

## 多项式乘法与后续方程

B2.15[移位、有限倒序与多项式乘法](manuscript/foundations/polynomial_multiplication.md#polymul-unit)与B2.16[结合、求值与次数](manuscript/foundations/polynomial_product_structure.md#polyprod-unit)已保存为新批草稿，各八题独立全解。先用单步移位与一维倒序建立正长度卷积候选及其全部系数公式；随后按可表示的原记录项数归纳，证明结合与求值相容。归纳覆盖全零尾部，不借一般双重换序；最高系数先证非零，再定义乘积次数。正式X及常量简记在运算规律之后出现。

## 一次除式、根数界之后

B2.17[一次除式的商余与综合除法](manuscript/foundations/polynomial_linear_division.md#polydiv-unit)和B2.18[因式定理、不同根界与恒等识别](manuscript/foundations/polynomial_roots_identity.md#polyroot-unit)已经保存，当前验收仍按实际文件与审查证据。商余归纳先建立存在和唯一，综合除法使用旧余数同步更新；因式定理由此进入次数归纳，最后才证明标准有理求值函数能够反向识别形式系数。有限点判等另外要求系数上界和足够多不同输入。两单元各八题独立完整答案，主归属仍是第528章97H20。
